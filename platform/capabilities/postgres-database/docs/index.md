# PostgreSQL database

A PostgreSQL database for a service, inside an ephemeral environment, ready
in a couple of minutes. You get a Secret with everything your service needs
to connect.

!!! note "Experimental"
    This capability is in the `experimental` stage: it works and is
    supported during business hours, but it may still change.

## When to use it

Use it when a service needs a relational database to test a change: in your
environment, with the same engine and versions as production. Do not use it
for production data: databases live and die with their environment and have
no backups locally.

## How to request it

=== "Portal"

    In the developer portal, **Create → PostgreSQL database**. Choose the
    environment, a name, the size and the version.

=== "kubectl"

    ```yaml
    apiVersion: platform.starterkit.dev/v1alpha1
    kind: PostgresDatabase
    metadata:
      name: orders-db
      namespace: env-payments-dev   # your environment
    spec:
      size: small                   # small (default), medium or large
      version: "17"                 # "16" or "17" (default)
    ```

=== "AI agent"

    Ask your agent, for example *"I need a database for the orders service in
    my environment"*. It uses `request_capability` in the platform MCP
    server.

| Parameter | Values | Default | |
|---|---|---|---|
| `size` | `small`, `medium`, `large` | `small` | Capacity. Larger sizes cost more. |
| `version` | `16`, `17` | `17` | PostgreSQL major version. |

## What you get

- A Secret `<name>-connection` with `host`, `port`, `database`, `username`
  and `password`. Mount it as environment variables in your service.
- In the resource status: `host`, `secretName` and the estimated cost per day.

```bash
kubectl -n env-payments-dev get pgdb
```

## Guardrails

| | Rule | |
|---|---|---|
| GR-1 | Databases can only be created in ephemeral environments (`env-*` namespaces). | Everyone |
| GR-2 | Each environment can have at most 2 databases. | Everyone |
| GR-3 | Agents can only create small databases on their own; medium and large need human approval. | Agents |

Estimated cost per day: small 0.50 EUR, medium 2.00 EUR, large 8.00 EUR.

The data is classified as confidential: the database only accepts
connections from pods in the same environment.

## Lifecycle

- It lives as long as its environment and is deleted with it.
- Deleting the request deletes the data. There are no backups locally.
- To resize it, change `size`. Agents need human approval for anything
  bigger than small.

## How it is built

Locally: plain PostgreSQL (official `postgres` Alpine image) with a
persistent volume, a Service and a NetworkPolicy, composed by Crossplane. No
operator. On AWS it will be Amazon RDS for PostgreSQL (not built yet).
